1. Universal Clear (`×`) Button on All Search Bars:
   - Added an instant `×` clear button inside every search input across the
     entire portal:
     * Utility Endorsements (`enrollSearchQuery`)
     * Request Bill Payment Account Combobox (`accountSearchQuery`)
     * Bill Payment Status (`paymentSearchQuery`)
     * User Management (`userSearchQuery`)
     * Account Number Management (`billerSearchQuery`)
     * User Activity Report (`repUserSearch`)

2. Account History Table Header Sorter & Inline Column Filters:

   - Removed `USR-...` / `APEC-USR-...` user ID codes from Account History so only
     the Assigned Filer's full name is shown.
   - Removed internal `BIL-...` account codes from Account History table, modal,
     and CSV exports.

5. Clickable Account Number -> 12-Month Payment History Popup (`Prev / Next` & CSV Export):
   - Clicking any Account Number in Account History opens a dedicated 12-Month
     Payment History modal for that account.
   - Includes `← Prev` and `Next →` navigation buttons to step through accounts

     December ledger table with clickable `REQ-...` inspector links and `+ File`

[v2.7.2] - 2026-11-09 — Fix In-Place Bill/Enrollment Detail Editing (No Duplicate Rows)
--------------------------------------------------------------------------------
1. Fixed Duplicate Row Appended When Editing Bill or Enrollment Details:
   - Root Cause: Saving billing edits (`updateBillingDetails`) or enrollment
     edits (`updateEnrollmentDetails`) previously dispatched the payload to BOTH
     the Bill Sub WebApp script (`USER_SCRIPT_URL`, which edits the row in place)
     AND the Approver's legacy Drive upload script (`PAYMENT_SCRIPT_URL` /
     `DEFAULT_APPS_SCRIPT_URL`), which lacked the `updateBillingDetails` handler
     and fell through to its `REQ-` / `ENR-` new-submission `appendRow` block.
   - Fix: Routed `updateBillingDetails` and `updateEnrollmentDetails` exclusively
     to `USER_SCRIPT_URL` (`DEFAULT_USER_SCRIPT_URL`) across React, Express
     server routes, and Standalone HTML so edits strictly update the existing
     row in place and never append a duplicate row copy.
   - Added automatic `requestId` deduplication during live Google Sheet GViz
     sync so any previously created `"No File Attached"` duplicate row is
     automatically collapsed into the original entry.

[v2.7.1] - 2026-11-08 — PLAN-LUT-RBP-SYNC: LUT_RBP_Status Formula-Safe Sync
--------------------------------------------------------------------------------
1. `LUT_RBP_Status` (Col H) <-> `Request Bill Payments` (Col M) Live Sync:
   - Fetches both `Request Bill Payments` and `LUT_RBP_Status` in parallel via
     Google Sheets GViz and matches rows by `Request ID` (Col A).
   - Evaluates the live result of conditional formulas / `IMPORTRANGE` in
     `LUT_RBP_Status` Col H (`Status`), plus Col I (`RFP`), Col J (`CV`), and
     Col K (`Pay Date`).
   - Ignores formula placeholders/errors (`#N/A`, `#REF!`, `Loading...`, `-`,
     `N/A`, blank) so Admin statuses in `Request Bill Payments` Col M (such as
     `UNDER REVIEW`, `APPROVED`, `BLURRED`, `REJECTED`) are never overwritten by
     unmatched formulas.
   - Strictly Read-Only on `LUT_RBP_Status` Col H: Portal status updates write
     ONLY to `Request Bill Payments` Col M and never overwrite the formulas in
     `LUT_RBP_Status` Col H.
   - Automatically writes resolved `LUT_RBP_Status` Col H statuses (`WITH RFP`,
     `CHEQUE REL`, `PAID`, etc.) into `Request Bill Payments` Col M.

2. Live Utility Tracker (LUT / Billers) & RBP Cross-Reconciliation:
   - Added 4-Card Live LUT <-> RBP Reconciliation Summary in Account Number
     Management (`Total LUT Accounts`, `Filed in RBP`, `Unfiled / Missing SOA`,
     and `Paid / Cheque Rel`).
   - Added `RBP Month` (`All Months` or `January`–`December`) and `Coverage`
     (`Filed in RBP`, `Unfiled / Missing SOA`, `RBP In-Progress`, `Paid / Cheque Rel`)
     filters to immediately spot utility accounts with missing monthly filings.
   - Added live `RBP Sync Status` column in Account Number Management showing
     either the clickable `REQ-...` Request Inspector badge + live payment
     status or an `UNFILED` badge with a 1-click `+ File RBP` shortcut.

3. `FILEDBY` Account Ownership & Reassignment (Billers Col D):
   - Extended `Billers` (`LUT`) schema to support `Col D: FILEDBY` (Assigned
     Filer User ID) and auto-links `FILEDBY` when an `RBP` or Endorsement is filed.

4. Table-Level Status Confirm-Before-Commit:
   - Changing a status dropdown directly inside the Payment Status or
     Enrollment Status table stages the new status with inline `Confirm` /
     `Cancel` buttons before committing to Google Sheets.

[v2.6.0] - 2026-11-07 — Request Inspector UX, Safety Locks & Layout Refinements
--------------------------------------------------------------------------------
1. Request ID Popup Trigger (No Row-Click Interference):
   - Removed full-row click triggers on Payment Status and Enrollment Status
     tables so Administrators and authorized users can freely click attachment
     links or change status dropdowns without accidentally opening the modal.
   - Retained the Request ID / Enrollment ID badge ("Inspect / Edit" or
     "Inspect") as the dedicated trigger to open the Split-Screen Request
     Inspector modal.

2. 2-Stage Edit Protection ("Edit Details" Unlock + Confirm Before Commit):
   - In the Split-Screen Request Inspector modal, users with edit permissions
     (Admin, Sub-Admin, PS_EDIT_BILLING, or ES_EDIT_DETAILS) now start with all
     form fields locked by default to prevent accidental edits.
   - Added an explicit "Edit Details" / "Cancel Edit" unlock bar in the left
     pane, followed by the "Confirm Before Commit" verification step before
     changes are written to Google Sheets.

3. Role-Gated "Open in New Tab" Attachment Access:
   - In both the Request Inspector attachment toolbar and table attachment
     columns, the "Open in New Tab" external link is now displayed ONLY for
     users with link access (Administrator, Sub-Administrator, PS_ATTACH_LINK,
     or ES_ATTACH_LINK).
   - Regular users without link permissions see "View-Only (No New Tab)" with
     right-click and drag-download disabled.

4. 10-Row Max Table Viewport & Bottom-Center "Move to Top" Button:
   - Updated both View Request Bill Payment Status and View Enrollment Status
     tables to display up to ~10 rows (`max-h-[450px]`) inside a themed scroll
     container.
   - Moved the circular "Move to Top" (`ArrowUp`) button outside the table
     frame at the bottom center of both status views.

5. Sync-Access-Only Technical Subtitles & GSheet Indicators:
   - "Real-time status updates synced live from Google Sheet (Request Bill
     Payments)" and "Live ledger of new utility endorsements (synced with New
     Bill Endorsement sheet)" along with live GSheet polling badges are now
     shown strictly to users with sync/management access.

6. Reorganized Filter & Search Control Bar + Custom Scrollbar Theming:
   - Consolidated Search, Status filter, Scope selector, count badges, and
     Refresh controls into a space-optimized single control bar.
   - Added custom theme-aware scrollbar styling (`::-webkit-scrollbar` and
     `scrollbar-color`) across Light, Dark, macOS, and Bazzite themes.

7. Zero Google Apps Script (`Code.gs`) Changes Required:
   - All updates operate seamlessly with the existing deployed Google Apps
     Script Web App endpoints.

8. Custom Browser Tab Icon (Favicon):
   - Applied the official APEC Homes Bill Submission icon (`Favicon_Bill_Sub`)
